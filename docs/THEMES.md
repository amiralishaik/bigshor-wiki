# BIGSHOR WIKI Theme Inventory

**Documentation baseline:** Consolidated release v34.10.0

| Component | Version | Purpose |
|---|---:|---|
| BIGSHOR WIKI Parent Theme | 23.5.0 | Shared presentation foundation, templates and styling |
| BIGSHOR WIKI Child Theme | 23.6.0 | Site-specific presentation/customization layer |

## Parent Theme — 23.5.0

Recorded theme-level work carried into the v34.10.0 release includes:
- Responsive and retina-aware brand images.
- Registered theme image sizes.
- Asynchronous image decoding where applicable.
- Deferred theme JavaScript.
- Open Graph and Twitter metadata.
- Primary-image structured data.
- Account-related pages configured for noindex and sitemap exclusion.

## Child Theme — 23.6.0

The child theme is the customization layer built on the parent theme. The exact file-by-file feature inventory has not yet been audited for this documentation set. See [Child Theme details](themes/CHILD-THEME.md).

## Compatibility

The child theme is intended to run with the BIGSHOR WIKI parent theme. The BIGSHOR WIKI Core plugin supplies platform functionality separately from theme presentation.

Minimum WordPress/PHP versions and exact dependency declarations must be confirmed from the actual package headers/readme files before deployment; they are not asserted here.
