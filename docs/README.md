## Accuracy policy

This documentation distinguishes recorded release information from verified runtime behavior. A source module, phase name or release note is not proof that an entire feature is complete. Unknown package requirements and unverified behavior are identified as such rather than guessed.

Update the relevant component document and release history whenever a theme or plugin is changed.
