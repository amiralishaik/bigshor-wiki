## Core — 34.10.0

The consolidated release uses Core v34.9.0 as its canonical base and integrates Phase70 media optimizer code from the v34.8.0 branch.

Recorded development areas include article experience, wiki framework, wikitext/parser development, article quality/layout, front-end editing, template engine, editorial governance/workflows, search routing, special pages, multilingual development, knowledge-graph/interoperability work, roles/permissions, account system, role applications and image delivery.

The presence of a phase module does not establish full feature completion. See [Core plugin details](plugins/CORE.md).
