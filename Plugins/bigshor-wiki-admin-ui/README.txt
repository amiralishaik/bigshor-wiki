BIGSHOR WIKI ADMIN UI v1.4.0

- Unified BIGSHOR design system across all administration and edit screens, not only Article Studio.
- Covers native post-type editors and lists, knowledge entities, wiki templates, talk pages, deletion discussions, standard pages, taxonomy editors, media library, contributor profiles, comments, moderation, plugins and settings.
- Standardised headings, form fields, buttons, notices, metaboxes, list tables, tabs, media dialogs and responsive layouts.
- Keeps the existing branded navigation shell, responsive behaviour and Article Studio integration.
- Uses WordPress administration APIs; does not modify WordPress core or the public website theme.
- Requires BIGSHOR WIKI Core v34.2.0 or later.

Install on staging first. Back up the site, deactivate the previous BIGSHOR WIKI Admin UI plugin, upload and activate this version. Keep BIGSHOR WIKI Core and public themes unchanged.


Version 1.5.0 adds a role-aware workspace landing page and global navigation search. Search indexes visible navigation destinations plus common actions; it does not search private content records or replace the Core search API.
