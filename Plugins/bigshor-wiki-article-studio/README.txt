BIGSHOR WIKI ARTICLE STUDIO — MERGED INTO CORE

Article Studio v1.4.0 is now a native module of BIGSHOR WIKI Core v34.11.0+.
The implementation and assets are stored in:
- Plugins/BIGSHOR_WIKI_CORE_v34.10.0/includes/article-studio.php
- Plugins/BIGSHOR_WIKI_CORE_v34.10.0/assets/article-studio.css
- Plugins/BIGSHOR_WIKI_CORE_v34.10.0/assets/article-studio.js

The old plugin entry point is a migration stub only. It automatically deactivates
when BIGSHOR WIKI Core is active. It contains no editor implementation.

BIGSHOR WIKI Admin UI remains a separate plugin and is not modified.
